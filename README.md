# 彩票统计工具（四种玩法 · 离线单文件）

一个**零依赖、零网络请求**的网页工具：开奖数据已内嵌在 HTML 里，双击即可打开，也能直接发给别人或部署成网址分享。

> 当前数据：双色球 2081 期、大乐透 2940 期、福彩3D 4791 期、排列三 7761 期。

---

## 一、四种玩法

顶部标签切换。分两类，**页面会自动换成对应版本**：

| 类型 | 彩种 | 规则 |
|---|---|---|
| **选号型** | 双色球（6 红 1-33 + 1 蓝 1-16）<br>大乐透（5 前区 1-35 + 2 后区 1-12） | 号码不重复、不分顺序 |
| **按位型** | 福彩3D、排列三 | 三位数字、每位 0-9，**可重复且分顺序**<br>（1 2 3 与 3 2 1 不是同一注） |

按位玩法的开奖记录多「形态 / 跨度」两列，走势改**按位折线**，统计改**按位统计**，中奖核对按直选 / 组三 / 组六判定。

## 二、页面功能（9 个页签）

| 页签 | 要点 |
|---|---|
| **开奖记录** | 5 列均可点表头排序（默认期号降序）、搜索框按期号/日期过滤、黄底＝红蓝号重合、每次加载 60 期 |
| **号码走势** | 历史号码分布（圆点内写号码、颜色与号码一致）+ 单号统计（几期没出 / 出现次数 / 平均间隔 / 最长遗漏 / 最近开出日期） |
| **出现次数** | 默认按次数**升序**，号码 / 次数 / 占比三列均可点，红球区与蓝球区独立 |
| **冷热分布** | 五级配色方格 + 最热/最冷前 3，窗口可切近一月 / 近一年 / 全部，可按号码或冷热排序 |
| **我的选号** | 点选 / 随机一注 / 条件机选（和值·奇偶·大小·三区，可生成 1~5 注）、**自动对奖**、复制文本、**生成投注图片** |
| **我的选号记录** | 每次添加自动归档、长期保留；可按彩种 / 已买未买 / 待开奖已开奖 / 日期区间**筛选**；每条可标记已买、可删除 |
| **中奖核对** | 号码盘点选，对最新一期或指定期号，出奖级与奖金；下方**奖项说明**含浮动奖当期实际单注奖金 |
| **复式 / 胆拖** | 自动算注数与金额，**红色大字标出总额**；3D/排列三为直选复式。⚠️ 金额随选号个数成倍增长 |
| **菜单** | 功能说明、数据来源、刷新数据、显示模式、管理员、生成授权码、访问授权 |

**顶部常驻**：最新一期摘要（含和值·奇偶比）、**当前奖池**、福运奖提示、**开奖倒计时**（每秒自更新）、数据更新于 / 当前时间（当前时间每秒跳动）。

## 三、访问授权（可选）

页面可设成**需要授权码才能打开**，避免链接被随手转发：

- **管理员**：菜单 →「管理员」登录 → 菜单常驻出现「生成授权码」
- **签发**：有效期可选 **天 / 周 / 月 / 年**，一次 1~20 个，到期日实时预览，可单个复制 / 复制全部 / 下载名单
- **新签的码不用重新构建页面**，直接发给对方即可激活；每个码自带到期日
- 激活后**与设备绑定**，换设备需重新激活；页面顶端常驻显示到期日，剩余 ≤7 天变红

```bash
python3 make_license.py --gen 10 --unit month --val 6   # 签发
python3 make_license.py --off                            # 关闭授权限制
```

⚠️ **边界要说清**：签发和验证都在页面内完成，密钥也在 HTML 里。它拦得住随手转发，**拦不住刻意破解**（删掉校验代码即可绕过）。要真正不可伪造、可随时吊销，必须配后端。

## 四、数据与刷新

| 彩种 | 来源 |
|---|---|
| 双色球、福彩3D | 中国福彩网 cwl.gov.cn |
| 大乐透、排列三 | 中国体彩 webapi.sporttery.cn |

体彩接口有 WAF，会概率性返回 403；程序已做多 UA 轮换 + 重试 + 并发补抓，可稳定取全量。**分页无上限**，抓到官方给完为止。

```bash
python3 build_single.py --refresh    # 重新抓取并生成单文件版
python3 build_static.py              # 生成静态站版
python3 build_serverless.py          # 生成阿里云 FC / 腾讯云 SCF 部署包
```

**GitHub Actions 自动刷新**：`.github/workflows/refresh-data.yml` 每天定时跑，数据有变化才提交（无变化写心跳文件，避免公开仓库 60 天被禁用定时任务）。

## 五、本地运行（Windows）

解压后 **双击 `启动本地服务.bat`** 即可，脚本会自动装依赖并打开服务。
也可以右键"以管理员身份运行"，或先 `cd` 到目录再手动执行。

| 脚本 | 作用 | 是否需要装依赖 |
|---|---|---|
| **`启动本地服务.bat`** | 启动后端，浏览器访问 `http://localhost:8000` | 是（脚本自动装） |
| **`刷新数据.bat`** | 重抓四彩种数据并重新生成单文件版 | 否（纯标准库） |

### 前提

- 安装 **Python 3.8+**（[下载](https://www.python.org/downloads/)），安装时勾选 **Add Python to PATH**
- 首次启动会 `pip install fastapi uvicorn`（走清华镜像），之后不再重装

### 三种看法，任选

1. **双击 `dist\单文件版\彩票统计.html`** —— 最省事，不用起服务，数据已内嵌
2. **双击 `启动本地服务.bat`** —— 起后端，数据实时抓取，适合开发调试
3. **部署到 GitHub Pages** —— 有网址可分享，见 `推送GitHub步骤.md`

> ⚠️ 直接双击 `static\index.html`（源码版）**打不开**——它要靠后端接口取数据，
> 必须通过 `启动本地服务.bat` 起服务后访问。要看成品请用 `dist\单文件版\` 里那个。

## 六、目录结构

```

├── 启动本地服务.bat           Windows 一键启动
├── 刷新数据.bat              一键重抓数据

├── lic_hash.py                口令散列
├── make_license.py            管理员 / 授权码签发

├── main.py                    后端（FastAPI）
├── app.py                     Vercel 入口
├── bootstrap / scf_bootstrap  阿里云 FC / 腾讯云 SCF 启动脚本
├── dist/
│   ├── 单文件版/彩票统计.html   成品，双击可看

    ├── refresh-data.yml      定时刷新数据
    └── deploy-pages.yml      发布到 GitHub Pages
```

## 八、提示

彩票完全随机，任何号码中奖概率相同。冷热、走势、出现次数仅为**已开奖结果的统计**，不具备预测能力。请理性购彩，量力而行。
