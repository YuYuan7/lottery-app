# 彩票查询 App（双色球 / 大乐透）

一个可在手机上直接打开的网页应用，**数据实时从官方接口抓取**，任何人访问链接都能用。

## 功能

- **双色球 / 大乐透** 一键切换
- **开奖记录**：期号、开奖日期、开奖号码、奇偶比、和值
  - 默认**期号降序**（最新在前），5 列均可点击排序
  - 蓝球（后区）与红球（前区）号码有重合的行，**黄底突出**
- **号码走势**（只保留分布图 + 统计卡，**无折线图**）
  - **历史号码分布**：左侧分两行＝**期号**（与开奖记录完全一致，如 2026122）+ **开奖日期**
    （完整 `YYYY-MM-DD`，含年份）；右侧列＝号码，彩色圆点＝该期开出的号码
    （圆点内写号码，颜色与号码一致），空白＝未开出；底部蓝球条标出最新一期
    - 默认显示最新 **20 期**，点「加载更多」每次 +20 期，可展开到全部历史；展开后按钮变「收起」
    - 33 列较宽，窄屏可左右滑动
  - **单号统计**：选一个号码 + 范围（近一个月 / 近一年 / 全部）
    - 三大指标＝**几期没出** / 历史出现次数 / 所选范围出现次数
    - 明细含平均间隔、当前遗漏、最长遗漏、最近一次开出日期（YYYY-MM-DD）
- **出现次数**：号码、出现次数、占比，**默认按次数升序**
- **冷热分布**：**颜色方格**（格内＝号码 / 该窗口出现次数），颜色按偏离理论次数的标准差
  - 极冷 / 偏冷 / 正常 / 偏热 / 极热 五色，下方直接列出最热、最冷三个号
  - 窗口可切换：**近一个月 / 近一年 / 全部历史**（当前窗口期数显示在下拉框右侧）
  - 可按号码或冷热排序；窗口越短样本越少，冷热波动越大
- **我的选号**：点选或「随机一注」添加，存在本机浏览器（不上传）
  - 添加前实时校验（缺球、多选、重复、蓝红重合）并提示，不合规时按钮置灰
  - 每注给出：是否历史开出过、**全史最相近**（期号 + 日期 + 重合哪几个号）
  - 可在菜单中清除本机选号

- **功能说明**：首次打开自动弹出，之后可从菜单随时查看；按模块逐条说明各页面怎么看
- **菜单**：标签栏**最左侧的「菜单」**页签，点开左侧抽屉，内含
  **功能说明 / 数据来源 / 刷新数据 / 清除本机选号**；首次打开自动弹一次功能说明
- 顶部常驻「最新一期」摘要

## 数据源

| 彩种 | 来源 | 说明 |
|---|---|---|
| 双色球 | 中国福彩网 cwl.gov.cn | 官方接口，一次可取全部历史 |
| 大乐透 | 中国体彩 webapi.sporttery.cn | 官方接口，分页抓取 |

体彩接口有 WAF，会概率性返回 403。程序已做**多 UA 轮换 + 重试 + 并发补抓**，实测可稳定取全量。

## 一、本地运行（先看效果）

```bash
pip install -r requirements.txt
python3 main.py
# 或 uvicorn main:app --reload --port 8000
```

浏览器打开 http://localhost:8000

手机测试：电脑与手机连同一 WiFi，用 `http://电脑内网IP:8000` 访问。

### 国外平台（需绑卡或国内访问不稳）

### 方案 A：Vercel（最省事）

1. 把整个 `lottery-app` 文件夹上传到 GitHub（新建仓库，拖进去即可）
2. 打开 https://vercel.com → 用 GitHub 登录 → **New Project** → 选中该仓库 → Deploy
3. 部署完成后会得到一个网址，如 `https://xxx.vercel.app`
4. 手机浏览器打开该网址即可，**可「添加到主屏幕」当 App 用**

> 注意：Vercel 免费版函数超时 10 秒。大乐透首次全量抓取约 3~7 秒，可能偶发超时；
> 超时后再刷新一次即可（结果会写缓存）。若频繁超时，改用方案 B。

### 方案 B：Render（无超时压力，更稳）

1. 同样先传到 GitHub
2. https://render.com → **New +** → **Web Service** → 连接仓库
3. 配置：
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
   - Plan: Free
4. 创建后等待几分钟，得到 `https://xxx.onrender.com`

> Render 免费版 15 分钟无访问会休眠，首次打开需等 30 秒左右唤醒。

### 方案 C：Railway

1. https://railway.app → New Project → Deploy from GitHub repo
2. 会自动识别 `railway.json`，直接部署，得到 `https://xxx.up.railway.app`

### 方案 D：自己的服务器 / Docker

```bash
docker build -t lottery-app .
docker run -d -p 8000:8000 lottery-app
```

## 三、环境变量（可选）

| 变量 | 默认 | 说明 |
|---|---|---|
| `LOTTERY_TTL` | 21600 | 缓存有效期（秒），默认 6 小时 |
| `LOTTERY_WORKERS` | 10 | 大乐透并发抓页数 |
| `LOTTERY_CACHE_DIR` | 系统临时目录 | 缓存文件存放位置 |

## 四、接口

| 接口 | 说明 |
|---|---|
| `GET /api/ping` | 健康检查 |
| `GET /api/history?lot=ssq` | 返回全部历史，`lot` 取 `ssq` 或 `dlt` |
| `GET /api/history?lot=ssq&force=1` | 强制刷新（忽略缓存） |

返回示例：

```json
{
  "name": "双色球", "redMax": 33, "blueMax": 16,
  "redCount": 6, "blueCount": 1,
  "rows": [["2026122","2026-10-25",[1,2,4,17,19,30],[9]], ...],
  "source": "live", "stale": false, "updatedAt": 1792983604, "count": 2080
}
```

`source`：`live`=刚抓取 / `disk`=磁盘缓存 / `cache`=内存缓存 / `stale`=官方接口暂时不可用，用的是上次缓存。

## 五、已知限制

- 大乐透官方接口有 WAF，偶发 403；程序会自动重试，极端情况会返回上次缓存并提示
- 大乐透 2013 年前的历史数据经检验存在分布偏差（卡方 234 vs 临界 48.6），仅供参考
- 页面数据用于查询与统计，**不能用于预测**
